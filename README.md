Bem-vindo ao meu portfólio profissional de Business Intelligence e Análise de Dados. Este projeto foi desenvolvido para demonstrar a aplicação prática de inteligência de dados na resolução de problemas complexos de negócios, englobando desde a engenharia e modelagem de dados até o design de dashboards executivos e recomendações estratégicas.

---

## 🚀 Destaques do Projeto & Skills Demonstradas

Além das análises de dados apresentadas, o próprio desenvolvimento e a evolução desta plataforma refletem competências em **Engenharia de Software, UX/UI e Resolução de Problemas**:

* **Integração Nativa de Dashboards:** Embed dinâmico de relatórios interativos do Power BI via `iframe` com otimização de proporção e layout responsivo.
* **Storytelling de Dados Orientado a Negócios:** Cada projeto apresenta a jornada completa: *Desafio do Negócio → Pipeline de Dados/SQL → Modelagem DAX → Insights Práticos e ROI*.
* **Melhorias de UI/UX & Refatoração:** Reestruturação de componentes React, padronização visual em formato widescreen (16:9), otimização do menu overlay e acessibilidade mobile.
* **Internacionalização (PT/EN):** Estrutura preparada para recrutadores internacionais com tags semânticas de idioma para tradução automática precisa no navegador e seletor global.
